# Spending pie / donut

Interactive category breakdown with a configurable pie or donut chart.

This folder is self-contained and can be uploaded to a static HTTPS host. For shared finance, habit, or event data, deploy all widget folders together on the same origin and use the same `?space=` value.

Use Settings for chart options and every theme color. The chart provides its own entry control or a direct link to the related widget. Personal entries stay in browser storage. Notion embedding may restrict that storage, so test save and reload in your actual Notion app.

Start with an embed height around 600px and resize after entering your data. Graphs and animations honor reduced-motion preferences. The Goal progress widget also has motion and 3D-depth switches.

The root README.md describes deployment, privacy, backups, and data sharing. No charting package, build step, or API key is required.
